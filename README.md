# Larps – Live

1. Suba `index.html` e a pasta `sounds/` na raiz do repositório.
2. No GitHub: Settings > Pages > Deploy from a branch > main / root.
3. Notebook (TV): abra `https://SEU-USUARIO.github.io/SEU-REPO/` e clique em "Ativar tela e som".
4. Celular: abra o mesmo link com `#celular` no final (ex.: `.../SEU-REPO/#celular`) e permita a câmera.

Os dois aparelhos precisam estar com internet. Para usar outra sala, acrescente `?sala=nome` nos dois links.
